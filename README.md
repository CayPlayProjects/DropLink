# DropLink v0.2.1

**DropLink** — локальный временный relay для быстрой передачи файлов, текста и ссылок между компьютером, телефоном и другими устройствами в одной сети.

## Что изменилось в v0.2.1

- полностью обновлён интерфейс: крупнее текст, чище структура и удобнее мобильная версия;
- отдельная панель **«Файлы комнаты»** — полученные файлы больше не нужно искать в общей ленте;
- поддержка выбора и drag & drop **нескольких файлов**;
- кнопка **«Скачать всё»** собирает файлы комнаты в один ZIP;
- опциональная **автозагрузка** новых файлов на принимающем устройстве;
- загрузка файлов теперь идёт потоково во временную папку, а не целиком в RAM;
- лимит по умолчанию: **256 МБ на файл** и **1 ГБ на комнату**;
- поддержка HTTP Range при скачивании файлов;
- улучшены сообщения об ошибках передачи;
- добавлен `START_DROPLINK.cmd` для быстрого запуска на Windows.

## Быстрый запуск на Windows

1. Установи Node.js 18+.
2. Дважды нажми `START_DROPLINK.cmd`.
3. Откроется `http://localhost:3000`.
4. Создай комнату и отсканируй QR-код телефоном.

Или из терминала:

```bash
npm start
```

## Подключение телефона

Телефон и компьютер должны быть в одной локальной сети Wi‑Fi/LAN.

DropLink покажет подходящий локальный адрес, например:

```text
http://192.168.0.102:3000
```

QR-код строится именно на основе LAN-адреса. Если телефон не открывает страницу:

- убедись, что оба устройства в одной сети;
- разреши Node.js доступ к **Private networks** в Windows Firewall;
- в блоке «Сетевой адрес» попробуй другой адаптер;
- нажми «Пересканировать».

## Лимиты

По умолчанию:

```text
FILE      256 MB
ROOM      1024 MB
TTL       10 / 30 / 60 min
MESSAGE   8000 chars
```

Лимиты можно изменить перед запуском.

CMD:

```bat
set MAX_FILE_MB=512
set MAX_ROOM_MB=2048
npm start
```

PowerShell:

```powershell
$env:MAX_FILE_MB=512
$env:MAX_ROOM_MB=2048
npm start
```

## Как хранятся файлы

Файлы временно записываются во временную папку операционной системы. Они удаляются:

- когда истекает время комнаты;
- когда сервер DropLink корректно останавливается;
- при следующем запуске DropLink очищает свою временную папку.

Постоянной базы данных и облачного хранилища нет.

## Важно

DropLink v0.2.1 — локальный HTTP relay, а не E2E P2P-мессенджер. Если выставлять его в публичный интернет, нужны отдельные меры безопасности, HTTPS и ограничения доступа.


## v0.2.1 — QR + LAN access fix

- исправлен двойной QR-код (резервное изображение QR больше не отображается поверх/под canvas);
